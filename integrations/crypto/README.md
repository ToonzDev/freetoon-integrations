# Crypto Tracker

Marketplace integration for FreeToon that tracks cryptocurrency prices via CoinGecko's free public API.

## Features
- **Tile**: Live price and 24h change for the configured primary coin.
- **Detail Screen**: Interactive price history chart across multiple timeframes (24h, 7d, 30d, 1y, max).
- **Multi-coin**: Configurable via `/mnt/data/integrations/crypto/crypto.conf`.
